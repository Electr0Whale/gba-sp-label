## 中文说明

用于日版 Game Boy Advance SP（AGS-001）机身背部标签的高精度 1:1 矢量复刻模板，专为老机翻新、换壳修复、品相复原与个人 DIY 打造。

### Release 资产清单

全套物料托管于本仓库的 **[GitHub Releases](https://github.com/Electr0Whale/gba-sp-label/releases)** 资产中：

- **`AGS-001-JPN.psd`**：完整可编辑的 Photoshop 分层工程源文件（支持自定义修改机身序列号）；
- **`AGS-001-JPN.png`**：300+ DPI 印刷级高分辨率无损导出预览图；
- **`Assets.7z`**：字体包（含条形码字体与 OCR B Std）及矢量图元支持包。

### 印刷与制作指引

1. **环境准备**：打开 PSD 前请先安装 `Assets.7z` 中的配套字体，防止字体自动替代引起间距走样；
2. **序列号修改**：如有专属编号需求，可定位至文字图层修改条形码与数字序列；
3. **尺寸标准**：**必须按 `72.6 × 25.1 mm` 原始物理尺寸打印**，避免缩放；
4. **材质建议**：推荐选用 **拉丝银 (Brushed Silver)** 或 **哑银 PET 不干胶贴纸**，表面覆防刮哑光保护膜以获得最贴近原厂的磨砂金属触感。

### 鸣谢与非商业声明

- 标签条形码及序列号字体参考了开源项目 [CharlieSIGMA/gb-label-creator](https://github.com/CharlieSIGMA/gb-label-creator)；
- 本项目专为复古硬件爱好者交流、个人收藏维修与 DIY 翻新使用，严禁用于翻新冒充原装正品销售等任何商业欺诈行为。

## English

High-precision 1:1 scale restoration template for the Japanese Game Boy Advance SP (AGS-001) rear casing label, tailored for reshelling, hardware refurbishing, and hobby restoration.

### Release Contents
Available on **[GitHub Releases](https://github.com/Electr0Whale/gba-sp-label/releases)**:
- `AGS-001-JPN.psd`: Layered, editable Photoshop source file
- `AGS-001-JPN.png`: High-resolution lossless print master
- `Assets.7z`: Associated typography and barcode resources

### Printing Specs
- Target size: `72.6 × 25.1 mm`
- Recommended substrate: Brushed silver / matte silver PET sticker with matte laminate
- Non-commercial and restoration use only.
